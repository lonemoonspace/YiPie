## YiPie v0.2.0 · 一瞥 v0.2.0

_2026-11-18_

Getting started takes a minute now: a welcome page walks you to a working model, whether you have a key, want to try for free, or run a model on your own computer. Answers also check their own citations against the page, and the extension has a name that says what it does.

上手只要一分钟了：欢迎页带你配好一个能用的模型，不管你已有 Key、想先免费试用，还是用本机模型。回答写完后会自动用原文核对引用，扩展名称也写明了它是做什么的。


### What's new

- First-run guide: installing the extension opens a welcome page with three ways in. **I have an API key**: pick a service, paste the key, and the page lists its models and picks one for you; "Test and save" checks the connection and saves it as the default model. **Try it for free**: services that had a free allowance when the list was made, each with a link to create a key. **Use a local model**: after you press "Detect local models", the page asks for access to this machine's addresses and lists the models you have downloaded in Ollama or LM Studio. No new required permissions.
- A panel with no model offers the same three ways in. Once a model is set up on the welcome page, the panel starts summarizing by itself. The settings page links to the guide while the model list is empty.
- Citation check: when an answer is complete, the panel looks for each citation in the text it read. Citations found on the page look as before; those not found get a dashed underline and a "?", and a line under the answer reads "Quotes found in the page text: M of N". A restored conversation with citations reads the page again to check them.
- The extension is now called "YiPie: AI Web Page Summarizer", or "一瞥 YiPie：AI 网页总结" in a Chinese-language browser. It used to be just "YiPie" ("一瞥 YiPie"), which held no word anyone searches for. The short description is rewritten too: it says you can ask follow-up questions, citations lead back to the page, and no sign-up is needed.

### Verification / 验证

- `npm run gate`: type check, unit tests, lint and format checks pass.
- Production build, manifest check and bundle budget check pass.
- `npm run verify:release` validates the package; it contains no source maps, `.env*` files, test leftovers or E2E hooks.

### Install

**Recommended**: install from the [Chrome Web Store](https://chromewebstore.google.com/detail/ikkkfhlajolneibfafbjfnmlnhonkmao). Edge can use the same link (open it in Edge and allow extensions from other stores).

**Manual**: download `yipie-0.2.0-chrome.zip` below, unzip it, then open `chrome://extensions` (`edge://extensions` in Edge), turn on Developer mode, click "Load unpacked" and choose the unzipped folder. Requires Chrome / Edge 110 or later — earlier versions refuse to install the package.

### 本版本更新内容

- 扩展名称加上一句说明：中文浏览器里显示「一瞥 YiPie：AI 网页总结」，其它语言显示「YiPie: AI Web Page Summarizer」；简短说明也改写了，写明能追问、引用能回到原文、不用注册，在应用商店里搜「网页总结」「summarizer」这类词时更容易找到它
- 首次使用引导：安装后自动打开欢迎页，给出三条路——已有 API Key（选服务、粘贴 Key，自动列出模型并选好一个，测试通过后保存为默认模型）、先免费试用（列出目前有免费额度的服务和申请 Key 的链接）、用本机模型（点「检测」后才申请访问本机地址，列出 Ollama 或 LM Studio 已下载的模型）。不新增任何必需权限
- 面板还没有模型时，直接给出这三条路；在欢迎页设置好后，面板自动开始总结。设置页的模型列表为空时也有「打开新手引导」的入口
- 引用自动核验：回答写完后，面板用读到的正文核对每条引用，原文里有的照常显示，没找到的标成虚线和「?」，回答下方显示「N 条引用，M 条在原文中找到」；恢复的对话里有引用时会再读一次正文来核对

### 安装

**推荐**：从 [Chrome 应用商店](https://chromewebstore.google.com/detail/ikkkfhlajolneibfafbjfnmlnhonkmao)安装，Edge 也可以用这个链接（在 Edge 里打开后允许来自其他应用商店的扩展）。

**手动安装**：下载下面的 `yipie-0.2.0-chrome.zip`，解压后打开 `chrome://extensions`（Edge 是 `edge://extensions`），开启「开发者模式」，点「加载已解压的扩展程序」，选择解压出的文件夹。需要 Chrome / Edge 110 及以上，更旧的浏览器会直接拒绝安装这个包。
