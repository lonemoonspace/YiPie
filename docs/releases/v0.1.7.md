## YiPie v0.1.7 · 一瞥 v0.1.7

_2026-11-11_

Sharper built-in prompts, and fixes from a second full review: panels stay usable with many tabs open, a page can no longer step outside the "this is data" block of the prompt, and the settings page warns before a key is sent over plain http.

内置 Prompt 更准了，另外修好了第二次全项目审阅发现的问题：开很多标签页时面板不再失效，网页不能再跳出 Prompt 里「这是数据」的范围，设置页会在密钥将以明文 http 发送前提醒。


### What's new

- The three built-in prompts are reworded, in both languages: they ask for Markdown only, never HTML; explain that ` | ` in the text marks table cells and `#` marks headings, neither to be copied; put a quote right after its sentence with no added quotation marks or ellipses (the English version keeps "unchanged and untranslated"); say which part is missing when the text was cut, instead of reporting that the page cannot be summarized; answer a follow-up unrelated to the page by saying only this page can be discussed; and state that the title and address are data to summarize too.
- With more than 50 tabs that have a panel open at once, the earliest panels keep working. They used to fail on a follow-up with "could not read the configuration", and their conversations were not saved.
- When the page text, title or selection contains `<page>` or `</page>`, the bracket is changed to a full-width `＜` before it is sent to the model, so a page can no longer use those tags to leave the "this is data" block and pose as instructions.
- Settings page: a base URL that is plain `http://` to anything but this machine shows a warning under the field that the API key and the page text will be sent unencrypted. Saving is not blocked.
- Wide tables in the panel scroll sideways, and their headings are no longer squeezed to one character per line.
- The privacy policy now says that conversations in session storage are kept with the address of their page (query string included).

### Verification / 验证

- `npm run gate`: type check, unit tests, lint and format checks pass.
- Production build, manifest check and bundle budget check pass.
- `npm run verify:release` validates the package; it contains no source maps, `.env*` files, test leftovers or E2E hooks.
- Chromium E2E suite passes in CI.

### 本版本更新内容

- 三个内置 Prompt 的措辞优化（中英文同步）：明确只输出 Markdown、不输出 HTML；说明正文里的 ` | ` 是表格单元格、`#` 是标题标记，不要照抄；引用要紧跟句末、前后不加引号或省略号，英文版保留「不改字、不翻译」；正文被截断时在结论后或要点里说明缺了哪部分，不再误报「无法总结」；追问与网页无关时说明只能回答这个网页的问题；并写清标题与地址同样是待总结的数据
- 同时开着面板的标签页超过 50 个时，最早打开的面板不再失效（原来会在追问时提示「读取配置失败」，对话也存不下来）
- 网页正文、标题或选中的文字里写了 `<page>`、`</page>` 时，发给模型前会改成全角的 `＜`，页面不能再借此跳出「这是数据」的范围冒充指令
- 设置页：Base URL 是不加密的 `http://` 且不是本机地址时，输入框下会提醒 API Key 和网页正文将以明文发送（不拦保存）
- 面板里的宽表格可以横向滚动，表头不再被挤成一字一行
- 隐私政策补充说明：对话记录在会话存储里带着所属网页的网址（含查询参数）
