## YiPie v0.1.8 · 一瞥 v0.1.8

_2026-11-18_

A name that says what the extension does, so the store search can find it. Nothing else changes.

扩展名称写明了它是做什么的，在应用商店里搜索更容易找到。功能没有变化。


### What's new

- The extension is now called "YiPie: AI Web Page Summarizer", or "一瞥 YiPie：AI 网页总结" in a Chinese-language browser. It used to be just "YiPie" ("一瞥 YiPie"), which held no word anyone searches for. The short description is rewritten too: it says you can ask follow-up questions, citations lead back to the page, and no sign-up is needed. Searching the store for words such as "summarizer" or "网页总结" should now turn it up.

### Verification / 验证

- `npm run gate`: type check, unit tests, lint and format checks pass.
- Production build, manifest check and bundle budget check pass.
- `npm run verify:release` validates the package; it contains no source maps, `.env*` files, test leftovers or E2E hooks.
- Chromium E2E suite passes in CI.

### Install

**Recommended**: install from the [Chrome Web Store](https://chromewebstore.google.com/detail/ikkkfhlajolneibfafbjfnmlnhonkmao). Edge can use the same link (open it in Edge and allow extensions from other stores).

**Manual**: download `yipie-0.1.8-chrome.zip` below, unzip it, then open `chrome://extensions` (`edge://extensions` in Edge), turn on Developer mode, click "Load unpacked" and choose the unzipped folder. Requires Chrome / Edge 110 or later — earlier versions refuse to install the package.

### 本版本更新内容

- 扩展名称加上了一句说明：中文浏览器里显示「一瞥 YiPie：AI 网页总结」，其它语言显示「YiPie: AI Web Page Summarizer」。原来只叫「一瞥 YiPie」（「YiPie」），里面没有会被搜索的词。简短说明也改写了，写明能继续追问、引用能回到原文、不用注册。在应用商店里搜「网页总结」「summarizer」这类词时，应该能找到它了

### Verification / 验证

- `npm run gate`：类型检查、单测、lint 与格式检查全部通过。
- 生产构建、manifest 检查与体积预算检查全部通过。
- `npm run verify:release` 校验安装包通过，不含 source map、`.env*`、测试残留与 E2E 钩子。
- CI 里的 Chromium E2E 套件通过。

### 安装

**推荐**：从 [Chrome 应用商店](https://chromewebstore.google.com/detail/ikkkfhlajolneibfafbjfnmlnhonkmao)安装，Edge 也可以用这个链接（在 Edge 里打开后允许来自其他应用商店的扩展）。

**手动安装**：下载下面的 `yipie-0.1.8-chrome.zip`，解压后打开 `chrome://extensions`（Edge 是 `edge://extensions`），开启「开发者模式」，点「加载已解压的扩展程序」，选择解压出的文件夹。需要 Chrome / Edge 110 及以上，更旧的浏览器会直接拒绝安装这个包。

使用说明见 [README.zh-CN.md](https://github.com/lonemoonspace/YiPie/blob/main/README.zh-CN.md)，各版本改了什么见 [CHANGELOG.md](https://github.com/lonemoonspace/YiPie/blob/main/CHANGELOG.md)，数据处理方式见 [PRIVACY.md](https://github.com/lonemoonspace/YiPie/blob/main/PRIVACY.md)。
